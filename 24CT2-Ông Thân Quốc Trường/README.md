## Hướng dẫn chạy ứng dụng Web (PyTorch + Flask)

1. **Kích hoạt môi trường ảo:**
   ```powershell
   D:\CNPM24\.venv\Scripts\activate
   ```

2. **Chạy server web:**
   ```powershell
   python d:\CNPM24\app.py
   ```
   *(hoặc vào thư mục sinh viên `cd "24CT2-Ông Thân Quốc Trường"` và chạy `python app.py`)*

3. **Mở trình duyệt truy cập:**
   👉 **http://127.0.0.1:5000**
